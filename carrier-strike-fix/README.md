# Carrier Strike — исправления (2026-11-24)

Исправленный `index.html` игры с https://etueque-blip.github.io/Avia/ (репозиторий etueque-blip/Avia).
Залей его в репозиторий Avia вместо старого `index.html`.

1. **Фон в меню/ангаре зависал** — функция звука `engineSound` падала каждый кадр (`player.thr` при `player = null`)
   сразу после первого касания (когда включается звук), и кадр не рисовался: оставался последний кадр (закат с огромным солнцем).
   Теперь проверка на `null`, а звук и блик солнца вызываются после отрисовки в отдельных `try` — их ошибка больше не останавливает картинку.
2. Одинаковая ошибка пишется в консоль один раз, а не 60 раз в секунду.
3. Авто-снижение графики не срабатывало на «высокой» и «ультра» (порог 0.51 при минимальном разрешении 0.7/0.85) — исправлено.
4. Меню и ангар: тени пересчитываются раз в 3 кадра (тени стоили столько же, сколько вся сцена).
5. iPad/телефон на «высокой»: карта теней 2048 вместо 4096.
6. Блик солнца не рисуется в меню и ангаре (слепил превью самолёта), холст блика не очищается каждый кадр впустую.
7. В ангаре освещение быстрее переходит с заката на день.
