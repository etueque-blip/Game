# Carrier Strike: полный гайд — от Studio до топа Roblox

Здесь всё по порядку: как запустить, опубликовать, зарабатывать, обновлять и продвигать игру.
Делай шаги сверху вниз. Если что-то не получается, пришли мне красный текст из окна **Output**.

## Часть 0. Что уже есть в игре и зачем

Roblox продвигает игры, в которые люди **возвращаются много дней подряд**, **играют долго** и **не уходят в первую минуту**. Поэтому в игре сделано так:

| Что сделано | Зачем |
|---|---|
| Большая кнопка **ИГРАТЬ**: сразу в воздух, в бой | новичок не уходит в первую минуту |
| **Обучение** в первом вылете: 4 короткие подсказки | новичок понимает игру за минуту |
| **Монеты и опыт**: за сбитие, помощь, захват, победу, посадку на палубу | есть ради чего играть |
| **Уровни** и **6 самолётов**, которые открываются за монеты и уровень | желание «докачаться» |
| **8 раскрасок**: камуфляж, арктика, ночь, акула, неон и золотая VIP | коллекция, хочется показать другим |
| **Награда за вход 7 дней подряд**, на 7-й день 750 монет | возвращаются каждый день |
| **3 задания каждый день** | цель на каждый день |
| **Серии сбитий** с бонусами, баннер «🔥 СЕРИЯ 5!» | азарт |
| **MVP раунда**: трое лучших с аватарками | гордость, хочется попасть в тройку |
| **Топ недели** по сбитиям, обнуляется по понедельникам | соревнование, каждую неделю новый шанс |
| **Позвать друзей** и **+20% монет**, если в игре есть друг | игроки приводят друзей |
| **VIP** (×2 монеты, золото, ★) и **пакеты монет** | заработок |
| **Значки** (badges) | ещё одна причина зайти |
| **Русский и английский**, язык выбирается сам | большинство игроков Roblox говорит по-английски |
| **Телефон**: крупные кнопки, авто-выравнивание крена, помощь в прицеливании | больше половины игроков Roblox сидят с телефонов |
| **Боты** добивают команды до 4 самолётов | в пустом сервере всё равно интересно |
| **Сохранения** (DataStore) | прогресс не теряется |

## Часть 1. Первый запуск

1. Скачай **Roblox Studio** с create.roblox.com (кнопка Start Creating) и войди своим аккаунтом.
2. Открой файл **CarrierStrike.rbxlx**: File → Open from File.
3. **Сразу опубликуй**, иначе не будут работать сохранения:
   File → **Publish to Roblox As…** → **Create new experience**.
   - Название: `Carrier Strike: Air Combat ✈️`
   - Жанр: **Action** (или Fighting)
   - Устройства: отметь Computer, Phone, Tablet, Console.
4. Включи сохранения в Studio: **Home → Game Settings → Security → Enable Studio Access to API Services** → Save.
5. Нажми **Play** (F5).
   - Океан, авианосцы и острова строит сервер при запуске, поэтому в редакторе до запуска мир пустой. Так и задумано.
6. Чтобы проверить игру с несколькими игроками: вкладка **Test** → в «Clients and Servers» выбери **2 Players** → **Start**. Проверь:
   - игроки попадают в разные команды;
   - видят и сбивают друг друга;
   - монеты начисляются.

   Закрыть: **Cleanup**.

**Если окно Output показывает красное:** скопируй строку целиком (там имя скрипта и номер строки) и пришли мне.
Жёлтое «DataStore недоступен» значит, что не сделан шаг 3 или 4. Игра при этом работает, только без сохранений.

**Если файл не открывается:** все скрипты лежат в **ВСЕ_СКРИПТЫ.txt**, перед каждым написано, куда его вставить.
- В ReplicatedStorage создай папку `CarrierStrike` и в ней 7 ModuleScript.
- В ServerScriptService создай Script `CarrierStrikeServer` и в нём 3 ModuleScript.
- В StarterPlayerScripts создай LocalScript `CarrierStrikeClient` и в нём 4 ModuleScript.
- Имена должны совпадать в точности.

## Часть 2. Страница игры: иконка, обложки, описание

Страница игры — это реклама. Решают иконка и первая обложка.

1. Открой **create.roblox.com → Creations**, выбери игру, затем **Configure** (или Places / Basic Settings).
2. **Иконка:** загрузи `promo/icon_512_3d.png` (3D). Есть и плоская версия `promo/icon_512.png`.
3. **Обложки (Thumbnails):** загрузи 3D-обложки `promo/thumb_dogfight_3d.png` и `promo/thumb_islands_3d.png` (плоские версии тоже лежат в promo/). Добавь 2–3 настоящих кадра из игры:
   - в Studio запусти Play, нажми **K**: интерфейс скроется и включится кинокамера;
   - повторное **K** переключает ракурсы (самолёт сбоку, сзади, авианосец, остров);
   - снимок экрана: клавиша Print Screen (или Win+Shift+S на Windows, Cmd+Shift+4 на Mac);
   - нужен размер 1920×1080.
4. Включи **Thumbnail Personalization** (если есть в настройках обложек). Roblox сам покажет каждому игроку ту обложку, по которой чаще кликают. После этого **не трогай обложки хотя бы 7 дней**, иначе система не успеет понять, какая лучше.
5. **Описание:** вставь готовый текст (английский первым, он важнее для поиска):

```
✈️ Take off from your aircraft carrier and fight for the ocean!
🔵 BLUE vs RED 🔴 — capture islands, shoot down enemy jets, win the round!

⭐ 6 real jets: F-16C, F/A-18E, Su-33, Rafale M, MiG-29K, F-35C
🎨 Unlock paint jobs, level up, climb the weekly leaderboard
🎁 Daily rewards and daily missions
🔥 Kill streaks, MVP of the round, missiles, flares, catapult launches
📱 Plays great on phone, PC, tablet and console

🇷🇺 Взлетай с авианосца, захватывай острова и сбивай врагов! Синие против красных.

Art credits: F/A-18E, Su-33, Rafale 3D models by andertan (Sketchfab, CC BY 4.0).
```

**Важно:** последняя строка про авторов моделей обязательна. 3D-обложки нарисованы по моделям с лицензией CC BY, а она требует указать автора.

6. **Max Players** (Places → Configure Place): **16**.
7. **Playability → Public.** Ответь на вопросы **Experience Questionnaire** (возрастной рейтинг): в игре стрельба по самолётам, без крови.

## Часть 3. Заработок (Robux)

Всё создаётся в **Creator Dashboard → твоя игра → Monetization**.

1. **VIP (Passes → Create a Pass):**
   - картинка: можно иконку;
   - цена: **199 Robux**;
   - после создания открой пропуск, скопируй **ID** (число в адресе страницы);
   - впиши его в Studio: ReplicatedStorage → CarrierStrike → **Config** → `VIP_PASS_ID = ЧИСЛО`.
2. **Монеты (Developer Products → Create):** три продукта.
   - «1 000 монет» — 49 Robux;
   - «3 000 монет» — 129 Robux;
   - «10 000 монет» — 349 Robux.

   ID впиши в `COIN_PRODUCTS` в Config, по порядку.
3. **Значки (Badges → Create a Badge):** «Добро пожаловать», «Первое сбитие», «Первый захват», «Первая победа», «Ас» (5 сбитий за вылет), «10 уровень».
   - ID впиши в `BADGES` в Config.
   - Создание значков может быть платным: смотри цену в Dashboard.
4. Опубликуй игру заново (File → Publish to Roblox).

Без ID магазин просто показывает «скоро», так что ничего не сломается.

## Часть 4. Звуки (сильно влияют на ощущения)

1. В Studio открой **View → Toolbox → Audio** (бесплатная библиотека Roblox).
2. Найди звуки: `jet engine loop`, `machine gun`, `missile launch`, `lock on beep`, `alarm`, `hit marker`, `coin`.
   - Музыка для меню — `action music`.
3. Правой кнопкой по звуку → **Copy Asset ID**.
4. Вставь в Config → `SOUNDS` в виде `"rbxassetid://ЧИСЛО"`.
5. Пустые строки — без звука, игра не ломается.

## Часть 5. Как обновлять игру

**Если обновление делаю я:**
1. Ты пишешь, что поменять.
2. Я меняю код в GitHub, собираю новый `CarrierStrike.rbxlx` и присылаю.
3. Ты открываешь файл в Studio и выбираешь **File → Publish to Roblox** (не «As…»: публикуешь в ту же игру).
   - Сохранения игроков не пропадут: имя хранилища в Config не меняется.
   - Перед публикацией перенеси свои ID из старого Config, если вписывал их сам. Или пришли их мне, и я впишу сразу в код.

**Если правишь сам:** меняй в Studio и снова **File → Publish to Roblox**.

**Чтобы все игроки сразу получили новую версию:** на странице игры в Creator Dashboard нажми «⋯» → **Restart servers for updates**. Игроки перезайдут на новые серверы.

**Ритм обновлений:**
- маленькое обновление каждую неделю (новая раскраска, событие);
- большое раз в 3–4 недели (новый самолёт, новая карта, вертолёты).

Название можно дополнять: `Carrier Strike [🚁 HELICOPTERS!]`. Новинка в названии поднимает клики.

## Часть 6. Как попасть в топ

Как Roblox выбирает игры для «Рекомендовано тебе» (по официальным материалам Roblox 2026 года):
- смотрит **28 дней**, а не 7: важнее всего, что игроки **возвращаются** днями и неделями;
- главные сигналы:
  - сколько **дней** человек играет;
  - сколько **минут**;
  - сколько новичков **уходит в первую минуту** (это плохо);
  - сколько остаются надолго («qualified play-through»);
- в зачёт идёт только первый **час** игры в день на человека;
- игроки, пришедшие через рекламу, друзей и соцсети, приносят деньги и онлайн, но в рейтинг рекомендаций их поведение не засчитывается. Значит, сама игра должна удерживать.

**План по шагам:**
1. **Неделя 1. Друзья и тест.**
   - Позови 5–10 друзей, поиграйте вместе.
   - Смотри **Creator Dashboard → Analytics**:
     - **Retention**: сколько процентов вернулось на 1-й и 7-й день;
     - **Engagement**: среднее время сессии.
   - Хорошие цифры: D1 больше 20%, D7 больше 5%, сессия больше 12 минут.
2. **Неделя 2. Реклама.**
   - Ads Manager (create.roblox.com → Ads) → **Sponsored Experience**.
   - Начни с маленького бюджета (например, 1 000–3 000 Robux на несколько дней).
   - Реклама приводит первых людей, а дальше держит сама игра.
3. **Соцсети.**
   - Короткие видео 15–30 секунд в TikTok, YouTube Shorts, Reels: взлёт с катапульты, сбитие ракетой, «СЕРИЯ 5».
   - В конце видео — название игры.
   - Это самый дешёвый способ привлечь игроков.
4. **Группа Roblox и Discord.**
   - Создай группу Roblox, позови туда игроков. Дальше можно сделать бонус за вступление в группу, я добавлю.
   - Сделай Discord-сервер для новостей обновлений.
5. **События по выходным.**
   - «Двойные монеты в выходные», «Неделя ракет».
   - Пиши, какое событие хочешь, я сделаю переключатель.
6. **Коды.**
   - Коды на монеты в описании и в видео (например, `CARRIER500`).
   - Это классика Roblox, я могу добавить ввод кодов.

**Честно о «топ-1».** В топе стоят игры с сотнями тысяч игроков онлайн и командами разработчиков. Реальные цели такие:
- 100 человек онлайн;
- потом 1 000;
- потом попадание в рекомендации.

Каждый шаг — это хорошие цифры удержания, регулярные обновления и видео. Игра уже собрана под эти цифры, остальное — регулярность.

## Если что-то сломалось

- Открой **View → Output**, скопируй **красные** строки и пришли мне.
- Ничего не нажимается, нет меню: проверь, что все скрипты на месте (Часть 1).
- Монеты обнуляются после выхода: не сделан шаг 3 или 4 из Части 1 (игра не опубликована или выключен доступ к API).
