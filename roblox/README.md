# Sky Pilot — Roblox

Авиасимулятор для Roblox, перенесённый из HTML-полигона `Sky Pilot` (тестовая копия).
Физика полёта перенесена **строка в строку** (`src/shared/FlightPhysics.luau` = `physicsStep` из HTML):
та же тяга, сопротивление, подъёмная сила, сваливание, отрыв на Vr, посадки с оценкой fpm и крушения.

## Как запустить (самый простой способ)

1. Скачайте файл **`roblox/SkyPilot.rbxlx`** из репозитория.
2. Откройте Roblox Studio → **File → Open from File** → выберите `SkyPilot.rbxlx`.
3. (Рекомендуется) В панели Explorer выберите **Lighting** → свойство **Technology** = `Future`.
4. Нажмите **Play** (F5). Мир, аэропорты, город и горы строятся скриптом при старте сервера.
5. Чтобы очки сохранялись: **Game Settings → Security → Enable Studio Access to API Services**
   (на опубликованной игре сохранение работает само).
6. Публикация: **File → Publish to Roblox**.

### Способ для разработчиков (Rojo)

```bash
rojo serve          # и подключиться плагином Rojo в Studio
# или
rojo build -o SkyPilot.rbxlx
```

Без Rojo файл места пересобирается так: `python3 tools/build_place.py`.

Города генерируются скриптом `python3 tools/gen_cities.py` (→ `src/shared/CityData.luau` и `tools/cities.json`).
Веб-версия (играть в браузере): `python3 tools/build_web.py` → `web/SkyPilot.html`.

## Что есть в игре

- **12 самолётов**: Sparrow S1, Swift 75, Aurora LX, Meridian 7000, Strato 320 / 330 / 350 / 380 (типы Airbus A320, A330, A350, двухпалубный A380),
  Skyliner 200 / 900, Titan 4, Striker X. Модели собираются из деталей: фюзеляж, стреловидные крылья,
  закрылки (реально отклоняются), шасси (убирается), двигатели, винт (крутится), огни (навигация, строб, маяк),
  инверсионный след выше 18 000 ft, форсаж у истребителя.
- **Мир**: аэропорты SKYPORT INTERNATIONAL (A) и MOUNTAIN VIEW (B) с полосами, разметкой, огнями,
  PAPI, рулёжками, терминалами, вышками, ангарами и стоящими самолётами; горы со снежными шапками; озёра, поля, лес, облака.
- **Города** (высоты знаковых зданий близки к настоящим, 1 stud ≈ 0,5 м):
  - **Дубай** (к северо-востоку от полосы A): Бурдж-Халифа 828 м, небоскрёбы (круглые, ступенчатые, закрученные), море,
    остров-«пальма», отель-«парус».
  - **Лондон** (к югу): Темза, Биг-Бен и парламент, Лондонский глаз, «Осколок», «огурец», Тауэрский мост,
    кирпичные дома со скатными крышами, Гайд-парк.
  - **Ташкент** (к востоку): телебашня 375 м, медресе с бирюзовыми куполами и минаретами, белая мечеть,
    купол Чорсу, Ташкент-Сити, сквер с фонтаном, гостиница «Узбекистан».
  - Над каждым городом видна большая подпись — по ней удобно ориентироваться.
- **Самолёты как настоящие**: отдельные иллюминаторы и двери, остекление кабины, турбовентиляторные двигатели
  (губа, вентилятор, кок, сопло), обтекатели крыла и механизации, светлое брюхо, тележки шасси, посадочная фара,
  ВСУ, подкосы у Sparrow, гребни и пусковые у Striker.
- **Старт**: на полосе A, на полосе B или в воздухе на заходе. Если полоса занята другим игроком — старт в воздухе.
- **Посадки и очки**: идеальная < 250 fpm, хорошая < 600 fpm, жёсткая — меньше очков, превышение лимита — крушение.
  Перелёт A → B (или обратно) даёт **+500**. Таблица лидеров: «Очки», «Посадки».
- **Крушения**: без шасси, жёсткое касание, удар крылом, здания, горы, край мира — взрыв и разлёт обломков.
- **ИИ-пилоты (агенты)**: 5 ботов летают по маршрутам между аэропортами и городом на той же физике
  через автопилот (`src/server/AITraffic.luau`, количество — `AI_TRAFFIC_COUNT` в `src/server/init.server.luau`).
- **Мультиплеер**: самолёт принадлежит игроку по сети (`SetNetworkOwner`), поэтому управление без задержки,
  а другие игроки видят ваш самолёт, шасси, закрылки и винт.

## Управление (чёткое, как в HTML + улучшения)

| Клавиши | Действие |
|---|---|
| W / S | нос вниз / вверх |
| A / D | крен, на земле — руление |
| Q / E | руль направления |
| Shift / Ctrl | тяга + / − ; Z — малый газ |
| F / R | закрылки выпустить / убрать |
| G | шасси, B — тормоз (держать), T — реверс на земле |
| P | **автопилот** (держит курс, высоту, скорость; отключается штурвалом) |
| C | **мышь-штурвал** (отклонение курсора от центра = отклонение штурвала) |
| N | **навигация**: стрелка, расстояние и курс до аэропорта или города; с целью автопилот летит к ней сам |
| V | камера: сзади / кабина / орбита (ПКМ — вращать, колесо — зум) |
| M | ангар (выбор самолёта, выход из самолёта) |

- **Телефон**: левый круг — штурвал (тяни вниз = нос вверх), справа — рычаг тяги, кнопки шасси/закрылки/тормоз/реверс.
- **Геймпад**: левый стик — штурвал, R2/L2 — тяга, R1/L1 — руль, Y — шасси, крестовина — закрылки,
  X — реверс, B — тормоз, A — автопилот, Select — камера.
- Аналоговый ввод (стик, мышь, тач) идёт через экспоненциальную кривую: точно возле центра,
  полный ход на краю. Сглаживание ввода — как в оригинале.

## Приборы

Скорость (kt), высота (ft, у земли — высота над землёй), вариометр (ft/min), курс, тяга, закрылки/шасси,
авиагоризонт, предупреждения: STALL, PULL UP (в т.ч. по рельефу впереди), ВЫПУСТИ ШАССИ,
превышение скорости закрылков и максимальной скорости. Кнопка «Отладка» показывает
все внутренние величины физики — как в HTML-полигоне.

## Структура

```
roblox/
  default.project.json        проект Rojo
  SkyPilot.rbxlx              готовый файл места для Studio
  tools/build_place.py        сборка .rbxlx без Rojo

    PlaneBuilder.luau         3D-модели самолётов из деталей
  src/server/                 ServerScriptService.SkyPilotServer
    init.server.luau          выдача самолётов, посадки, очки, крушения
    WorldBuilder.luau         постройка мира
    AITraffic.luau            ИИ-пилоты
    Scores.luau               leaderstats + DataStore
  src/client/                 StarterPlayerScripts.SkyPilotClient
    init.client.luau          цикл полёта, события, приборы
    Controls.luau             клавиатура / геймпад / тач / мышь
    CameraRig.luau            камеры
    Animator.luau             винты, огни, шасси, закрылки, след
    Ui.luau                   весь интерфейс
```

## Настройка

- Звук двигателя: впишите id звука в `ENGINE_SOUND_ID` (`src/shared/PlaneConfigs.luau`).
- Новый самолёт: добавьте запись в `PLANES` и его id в `ORDER` — модель построится автоматически.
- Новый аэропорт: добавьте запись в `World.AIRPORTS` — полоса, разметка, терминал и столкновения появятся сами.
